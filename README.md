# Mapa de Prospectos

CRM para registrar e organizar prospectos por família, amigos, redes sociais, comunidade e trabalho.

**Criado e desenvolvido por Maxine Lobato Lima.**
© 2026 Maxine Lobato Lima. Todos os direitos reservados. Veja [LICENSE](LICENSE).

## Rodar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

Feito com [Next.js](https://nextjs.org), Tailwind CSS e Supabase.
